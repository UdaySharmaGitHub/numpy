### Addition on NumPy arrays of different sizes or same size
- To perform an addition on NumPy arrays of different sizes, your approach depends on whether you mean mathematical element-wise addition or concatenating/appending elements to grow the array.
1. Mathematical Addition (Element-Wise)
  1. Via Broadcasting (For compatible shapes)
  2. By Zero-Padding (For completely incompatible shapes)
  3. Using polyadd (For 1D vectors representing polynomials)

2. Combining / Joining Arrays (Concatenation)
  1. Concatenating 1D arrays
  2. Stacking 2D arrays of different sizes
